# Homebrew CLImate Tap

Homebrew tap for [CLImate](https://github.com/JonW91/CLImate) - Terminal weather forecasts with ASCII art.

## Installation

```bash
brew tap jonw91/climate
brew install climate
```

## Usage

```bash
climate London
climate --today Paris
climate --hourly "New York, NY"
climate --units imperial Chicago
```

## Updating

```bash
brew update
brew upgrade climate
```

## Uninstalling

```bash
brew uninstall climate
brew untap jonw91/climate
```
